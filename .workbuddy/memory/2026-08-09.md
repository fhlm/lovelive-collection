## 分析 lovelive-collection 项目功能

- **项目概述**：Love Live! 系列趴趴（寝そべりぬいぐるみ）图鉴收集工具。
- **功能特点**：
  - 收录 706 款趴趴商品，覆盖 6 大系列（μ's、Aqours、虹咲学园、Liella!、莲之空、いきづらい部）。
  - 支持勾选收藏进度，数据保存在 localStorage。
  - 提供搜索、筛选、排序功能。
  - 缩略图放大查看。
  - 中日文界面切换。
  - 手机端 H5 适配。
  - 版本标注（通常版、限定版等）。
- **技术实现**：单文件 HTML（内联 CSS、JavaScript、数据），无需外部依赖。缩略图存放在 thumbs/ 目录，按系列分子文件夹。
- **数据来源**：官网新闻、公开信息、个人 Excel 图鉴整理。
- **部署方式**：GitHub Pages。

## 修复搜索框位置变化问题

### 问题分析
用户反馈：选择某个系列后，搜索框的位置会变，不希望根据筛选项的勾选影响到UI结构。

### 可能原因
1. **flex-wrap:wrap**: toolbar 使用 flex-wrap:wrap，可能导致换行
2. **flex:1 1 180px**: 搜索框使用 flex:1 1 180px，可能导致宽度变化
3. **内容高度变化**: 筛选后内容数量变化，导致页面布局重新计算

### 解决方案
修改 toolbar 的 CSS 样式：
1. **flex-wrap:nowrap**: 防止换行
2. **position:sticky**: 固定 toolbar 在顶部
3. **z-index:100**: 确保 toolbar 在其他内容之上
