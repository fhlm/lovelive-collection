
# Love Live 生日日历订阅

整理 Love Live 角色与声优生日，生日按每年自动重复。可复制链接，在支持 ICS/URL 订阅的手机日历中添加。

> GitHub 仓库需要设为公开，否则日历应用无法读取 Raw 链接。

## 全员日历

包含所有团体的完整日历：

- [仅角色生日](https://raw.githubusercontent.com/fhlm/lovelive-collection/main/calendar/lovelive_characters_birthdays.ics)
- [仅声优生日](https://raw.githubusercontent.com/fhlm/lovelive-collection/main/calendar/lovelive_voice_actors_birthdays.ics)
- [角色与声优生日](https://raw.githubusercontent.com/fhlm/lovelive-collection/main/calendar/lovelive_characters_and_voice_actors_birthdays.ics)

## 使用方法

在手机日历中选择“添加日历”“订阅日历”或“通过 URL 导入”，粘贴对应链接即可。不同手机对“生日”类型、图标和分类的显示可能略有差异。

项目地址：[fhlm/lovelive-collection](https://github.com/fhlm/lovelive-collection)
