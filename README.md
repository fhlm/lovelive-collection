# 🎀 Love Live! 系列趴趴图鉴（Love Live! Nui Collection Checker）

ラブライブ！シリーズ 寝そべりぬいぐるみ コレクションチェッカー

> Love Live! 全系列「趴趴」（寝そべりぬいぐるみ / 棉花娃娃）收藏进度追踪工具。

在线访问：https://fhlm.github.io/lovelive-collection/

## 功能

- 📋 收录 μ's / Aqours / 虹咲学园 / Liella! / 莲之空 / いきづらい部 共 **706 款趴趴**商品（按系列 · 款式 · 尺寸组织）
- 💗 勾选「已收藏」，进度保存在本地浏览器（localStorage），关闭页面不丢失
- 🔍 搜索（款式 / 角色 / 系列）、按系列筛选、按角色筛选
- 📅 默认按发售时间排序（早→晚 / 晚→早可切换）
- 🖼️ 点击缩略图放大查看
- 🌐 右上角中日文界面切换，默认跟随系统语言
- 📱 手机端 H5 适配
- 🏷️ 版本标注：通常版 / 限定版（711限定、くじ、UFO限定、コラボ等）

## 数据来源（按优先级）

1. **官网新闻（首要）**：[Love Live! 官网新闻](https://www.lovelive-anime.jp/news/) 中以「寝そべり」为关键词检索到的商品新闻（覆盖 2024.11 ~ 2026.08，共 28 条），用于核对发售批次与商品名。
2. **网络公开信息（次要）**：各系列官网 GOODS 页面、商品发售信息等公开资料。
3. **个人图鉴整理（补充）**：基于用户整理的《Love Live! 趴趴图鉴》Excel（749 张商品图、6 大团体），整理出 706 款唯一商品条目；商品图片即来自该图鉴。

> ⚠️ 发售日期：官网新闻能确认的款式使用新闻日期；其余款式为按系列发售时间线整理的**近似值**（精确到年月），仅供参考。图片为个人图鉴整理，可能与实际商品存在色差或版本差异。

## 部署方式（GitHub Pages）

1. 在 GitHub 创建仓库 `lovelive-collection`（Public）。
2. 上传本目录下的 **`index.html`、`thumbs/`、`README.md`** 三个文件/目录（不含任何构建脚本与本地配置）。
3. 仓库 **Settings → Pages** → Source 选择 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`，保存。
4. 等待几分钟后访问 `https://<你的用户名>.github.io/lovelive-collection/` 即可。

> 提示：`thumbs/` 内图片文件名包含中文/日文，上传时保持原样即可，浏览器会自动处理编码。

## 本地预览

直接双击 `index.html` 即可在浏览器打开（无需服务器）。若需完整模拟线上环境，可运行：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```
